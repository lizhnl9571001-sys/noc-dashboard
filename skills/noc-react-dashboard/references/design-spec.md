# 设计规范

基准1920×1080，等比缩放并居中。Header74、KPI116、中部660、底部190、Footer40。两侧316，外边距18，间距14。面板圆角6，浮窗5，按钮4，徽标2。

科技蓝：主色#00D4FF，强调#34F5FF，正常#00E89C，重要#FFB020，严重#FF3B5C，正文#CFEAFF，辅助#7FB7DD。颜色必须配合文字与符号。

原稿正文12、面板标题14、数值25；远距离正文18、标题20、数值32起，提升字号同时降低密度。弱发光，装饰动效可关闭。

缺失显示—，真实0显示0。加载、空、失败、过期单独呈现。失败保留旧数据并标记过期。等级与处理状态分开；恢复不等于关闭。告警点击携带resourceId。图层切换保留时间范围，下钻返回保留上下文。自动滚动可暂停，悬停及键盘聚焦暂停。

当前实现范围：基础组件、静态趋势与城域拓扑、图层入口、告警选择、详情卡、等比缩放。未实现：真实GeoJSON、不同图层实际数据、远程接口、完整处理闭环、真实刷新。SVG图表用于轻量示例；复杂图表可用公司ECharts方案替换，保持组件接口与规范。
